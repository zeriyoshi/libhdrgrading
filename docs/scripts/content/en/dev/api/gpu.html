The app's GPU: the device and queue the app shares with the library and its filters ({{api:hdrg_context_set_device}}), the frames a session takes and gives on that GPU ({{api:hdrg_device_frame_t}}), and the shaders and the state to run the apply pass on the app's own GPU ({{api:hdrg_shader}}, {{api:hdrg_apply_state_t}}). Includes hdrgrading.h; video.h and plugin.h include it.
