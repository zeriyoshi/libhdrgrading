The ABI a codec plugin implements: a reader (probe and read) or a writer (create, rows, finish, destroy) as a class of a plugin, on the same API table as the filters ({{page:api/filter}}). The built-in JPEG, PNG, GIF and JPEG XL and the AVIF and HEIF modules are written on it. Not frozen.

The host's side (the readers tried in turn, the writer chosen with {{api:hdrg_context_set_writer}}, its options) is in {{page:api/plugin}}; {{man:still}} describes the writers and their forms.
