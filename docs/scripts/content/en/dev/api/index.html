version.h (made by CMake from version.h.in) defines HDRG_VERSION_MAJOR, HDRG_VERSION_MINOR, HDRG_VERSION_PATCH and HDRG_VERSION_STRING; {{api:hdrg_version}} returns the library's string at run time.

Conventions of the API

  • A function that can fail returns an {{api:hdrg_status_t}} (a few return NULL or 0 instead). {{api:hdrg_status_string}} names a status; {{api:hdrg_context_error}} gives the detail of a failed plugin, filter or option call.
  • Settings structs are initialized with their *_init function (the defaults live in the library, so they can be re-tuned) and carry struct_size; NULL stands for the defaults.
  • A context is used by one thread at a time; distinct contexts are independent. A session likewise.
  • Buffers the library returns are freed with {{api:hdrg_free}}, even after the context is gone.
  • Constants are fixed integers (UINT32_C / UINT8_C), never renumbered; status codes are only added.
  • The library is 0.x: a minor version may break the API. The filter ABI ({{api:HDRG_PLUGIN_ABI_VERSION}} 1) is not frozen.

Lifecycle at a glance

hdrg_context_desc_init(&desc);            /* allocator, threads, SIMD cap, GPU */
hdrg_context_create(&desc, &ctx);
  hdrg_context_load_plugin(ctx, path);     /* optional: plugins, filters, a device */
  hdrg_context_add_filter(ctx, HDRG_STAGE_SCALE, "hdrg.scale.edge", NULL);
  hdrg_convert(ctx, ...);                  /* stills, any number of times */
  hdrg_session_create(ctx, ..., &session); /* video */
    hdrg_session_send_frame / hdrg_session_receive_frame ...
  hdrg_session_destroy(session);
hdrg_context_destroy(ctx);
