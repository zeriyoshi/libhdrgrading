Ground rules

  • The library is not finished: backward compatibility is not kept, and the plugin ABI stays at version 1 until it is frozen.
  • When files or names change, {{src:CLAUDE.md}} (the file structure) is updated with them.
  • The output is deterministic and that is tested: a change that makes the output depend on the thread count, the FP environment or the run is a bug ({{page:conventions}}).
