フレームのサイドデータ。アプリとフィルタが共有する形式です: ノイズ ({{api:HDRG_SD_NOISE}}。解析のもので、フィルタへ渡す)、動き ({{api:HDRG_SD_MOTION}}: アプリかフィルタのベクトル)、コーデックの粒のパラメータ ({{api:HDRG_SD_FILM_GRAIN}}: アプリがデコーダから受け取ったもの)。セッションのフレームは動きと粒をこの形式で受け取ります。video.h と filter.h がこれを含みます。各項目の説明はヘッダのコメントを日本語に訳したもので、その下に英語の原文を開けます。

フィルタがそれをどう読み書きするかはマニュアルの{{man:plugins}}が説明します。
