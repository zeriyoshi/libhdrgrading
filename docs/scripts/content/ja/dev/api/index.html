version.h (CMake が version.h.in から作る) は HDRG_VERSION_MAJOR・HDRG_VERSION_MINOR・HDRG_VERSION_PATCH・HDRG_VERSION_STRING を定義します。{{api:hdrg_version}} は実行時にライブラリの版の文字列を返します。

API の約束

  • 失敗しうる関数は {{api:hdrg_status_t}} を返します (いくつかは代わりに NULL か 0)。{{api:hdrg_status_string}} が状態の名前を返し、{{api:hdrg_context_error}} が失敗したプラグイン・フィルタ・オプションの呼び出しの詳細を返します。
  • 設定の構造体は *_init で初期化し (既定値はライブラリの中にあるので調整し直せる)、struct_size を持ちます。NULL は既定値です。
  • コンテキストは 1 度に 1 つのスレッドから使い、別のコンテキストは独立です。セッションも同じです。
  • ライブラリが返すバッファは、コンテキストを壊した後も {{api:hdrg_free}} で解放します。
  • 定数は決まった整数 (UINT32_C / UINT8_C) で、番号を振り直しません。状態の値は足すだけです。
  • ライブラリは 0.x です: minor が上がると API が壊れえます。フィルタの ABI ({{api:HDRG_PLUGIN_ABI_VERSION}} 1) はフリーズしていません。
