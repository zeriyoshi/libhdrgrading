コーデックプラグインが実装する ABI: 読み手 (probe と read) か書き手 (create・rows・finish・destroy) を、フィルタと同じ API 表 ({{page:api/filter}}) の上でプラグインのクラスとして作ります。内蔵の JPEG・PNG・GIF・JPEG XL と、AVIF・HEIF のモジュールはこの上で書かれています。フリーズ前。各項目の説明はヘッダのコメントを日本語に訳したもので、その下に英語の原文を開けます。

ホストの側 (読み手を順に試すこと、{{api:hdrg_context_set_writer}} で選ぶ書き手、そのオプション) は {{page:api/plugin}} にあります。書き手と形はマニュアルの{{man:still}}が説明します。
