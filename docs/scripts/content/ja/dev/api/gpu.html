アプリの GPU: アプリがライブラリとそのフィルタと共有する device とキュー ({{api:hdrg_context_set_device}})、その GPU の上でセッションが受け取り返すフレーム ({{api:hdrg_device_frame_t}})、アプリ自身の GPU で適用を走らせるためのシェーダと状態 ({{api:hdrg_shader}}・{{api:hdrg_apply_state_t}})。hdrgrading.h を含み、video.h と plugin.h がこれを含みます。各項目の説明はヘッダのコメントを日本語に訳したもので、その下に英語の原文を開けます。

ライブラリが GPU のどこで動き、フレームがどう GPU に留まるかはマニュアルの{{man:gpu}}が説明します。
