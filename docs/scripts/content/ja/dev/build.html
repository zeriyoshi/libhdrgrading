ライブラリの依存は third_party/ のソースから CMake が組みます (事前のビルドなし)。AVIF と HEIF のモジュールはシステムの libavif / libheif を使います。1 つのコマンドでプリセットの構成・ビルド・テストができます。

最初のビルド

scripts/fetch_deps.sh                              # submodule と jpegli の入れ子の依存
scripts/jobs.sh cmake --workflow --preset dev      # 構成 + ビルド + テストを空きメモリに合わせた並列で

{{src:scripts/jobs.sh}} は CMAKE_BUILD_PARALLEL_LEVEL と CTEST_PARALLEL_LEVEL を min(コア数, (空きメモリ − 総量の 1/8 (最低 2 GiB)) / 1 GiB) にし、空きメモリに 1 ジョブ分の余裕もなければ警告して 1 ジョブずつ走らせます。Linux は開発イメージで動かします: {{src:scripts/docker_dev.sh}} が DevContainer ({{src:.devcontainer}}: Debian 13・LLVM 23・GCC 16・Valgrind・emsdk・lavapipe 付きの Dawn・VapourSynth・FFmpeg・GStreamer) と同じイメージでコマンドを走らせ、ビルドディレクトリは build/linux-<preset> です。コンテナの ~/.cache (Emscripten のシステムライブラリと port、ccache) は実行をまたいで残る Docker のボリュームで、HDRG_DEV_CACHE を指定するとホストのディレクトリをそこにマウントします。

主なオプション

名前は 1 つの流儀です: HDRG_WITH_<名前> は依存・バックエンド・組み込む機能、HDRG_BUILD_<名前> はライブラリの隣に作るもの、HDRG_PLUGINS_EXCLUDE は外す内蔵プラグイン。

オプション既定効果
BUILD_SHARED_LIBSOFFHDRG_API の関数だけを公開する共有ライブラリ
HDRG_BUILD_TOOLS・HDRG_BUILD_TESTSトップレベルなら ONツール (hdrg-cli・hdrg-video・hdrg-inspect、FFmpeg があれば hdrg-ffmpeg)、テストと開発者向けのツール (hdrg-bench・hdrg-predictor-data)
HDRG_WITH_LCMS2ONLUT 型の ICC の入力、P3 / PQ のプロファイルの生成、JPEG XL の書き手の色の管理 (なければ jxl の系統を外す)
HDRG_PLUGINS_EXCLUDE(空)ライブラリから外す内蔵プラグインの一覧: 系統 bilinear・denoise・deblock・dering・defringe・deband・mctf・interp・fsr・nis・edge・predict とコーデック jpeg・png・gif・jxl、またはまとまり filters・codecs・all (polyphase はいつも残る。コーデックはそれぞれ自分の依存を連れてくるので、外した系統の依存は組まない)
HDRG_WITH_AVIFOFFAVIF のモジュール、読み書き (システムの libavif 1.2 以降、pkg-config で)
HDRG_WITH_HEIFOFFHEIF のモジュール、書き (libheif)
HDRG_WITH_SIMD・HDRG_WITH_SIMD_FMAON・ONSIMD のカーネル、その中の積和の融合 (無効なら全階層が scalar とバイト一致。Debug のプリセットは無効にする)
HDRG_WITH_TEMPORALOFF時間方向の機能: フレームをまたぐ統計 (内蔵の STATS のフィルタ hdrg.stats.temporal: そのときセッションの過去のウィンドウの既定は 8)・hdrg.interp.mc・hdrg.scale.temporal。それぞれは HDRG_WITH_TEMPORAL_FILTER・_INTERP・_SR で (AUTO: まとめに従う、ON、OFF)
HDRG_WITH_WEBGPUDawn があればWebGPU のフィルタとコア (scripts/build_dawn.sh が Dawn を build/deps/dawn に組む)
HDRG_WITH_METALApple で ONMetal のフィルタ・コア・MetalFX、CVPixelBuffer のフレーム
HDRG_WITH_VULKANVulkan のヘッダがあればVulkan のフィルタとコア (ローダーは実行時に開く)
HDRG_WITH_FFMPEG・HDRG_BUILD_GSTREAMER・HDRG_BUILD_VAPOURSYNTH見つかればhdrg-ffmpeg とその補助、バインディング
HDRG_BUILD_GUI・HDRG_GUI_MEDIAOFF・platformhdrg-gui、そのデコーダとエンコーダ (プラットフォームのもの、または ffmpeg)
HDRG_WITH_SYSTEM_DEPSOFFシステムの zlib・libpng・giflib・lcms2 (jpegli・Highway・libjxl・brotli はいつも同梱)
HDRG_WARNINGS_AS_ERRORSトップレベルなら ON警告でビルドを失敗にする (別に組むプラグインのプロジェクトは決定性のフラグだけ)
HDRG_MEMORY_HEADER(なし)既定の確保のマクロを差し替えるヘッダ
HDRG_INSTALLトップレベルなら ONinstall の規則・CMake のパッケージ・pkg-config

既定で OFF のオプション

HDRG_WITH_TEMPORAL (HDRG_WITH_TEMPORAL_FILTER・_INTERP・_SR も)・HDRG_WITH_AVIF・HDRG_WITH_HEIF は、第三者の権利との関係で利用が安全だと言い切れないため、既定で OFF にしています。有効にする場合は自己責任で行い、ご自身でビルドしてください。プリセットの temporal・avif・heif とカバレッジのプリセットは、このプロジェクトの検証のために ON にするもので、どれかを ON にした構成は CMake がそのことを知らせます。

GPU の道具

  • Dawn: {{src:scripts/build_dawn.sh}} がピンしたタグを build/deps/dawn に組みます (開発イメージは /opt/dawn。タグは Dockerfile の DAWN_TAG と一致させる)。
  • Tint: scripts/build_dawn.sh --tint が Tint の CLI を作り、{{src:scripts/gen_shaders.sh}} が WGSL から MSL・SPIR-V・HLSL を作り直します (--check は差分で失敗)。生成物は WGSL と一緒にコミットします。
  • Vulkan: ビルド時はヘッダだけ。開発イメージでは Mesa の lavapipe でテストを走らせます。
  • Apple シリコンでの x86: -DCMAKE_OSX_ARCHITECTURES=x86_64 -DHDRG_WITH_WEBGPU=OFF で Rosetta 2 の上で動きます (SSE4.1、ROSETTA_ADVERTISE_AVX=1 で AVX2)。

FFmpeg

開発イメージは Debian の FFmpeg 7.1 です。macOS では {{src:scripts/build_ffmpeg.sh}} が最新の stable を build/deps/ffmpeg に組み、PKG_CONFIG_PATH=$PWD/build/deps/ffmpeg/lib/pkgconfig で構成します。FFmpeg のフィルタは、共有ライブラリを install し (cmake --install build/release --prefix build/deps/hdrgrading)、scripts/build_ffmpeg.sh --filter build/deps/hdrgrading でパッチを当てた FFmpeg を build/deps/ffmpeg-filter に組み、その pkg-config のパスで構成すると test_filter が加わります (-DHDRG_WITH_TEMPORAL_INTERP=ON ならフィルタの fps も確かめます。フィルタはテストのビルドのライブラリを読みます)。

WebAssembly

scripts/docker_dev.sh bash -c 'source "$HDRG_EMSDK_DIR/emsdk_env.sh" && cmake --workflow --preset wasm'
scripts/docker_dev.sh scripts/wasm_demo.sh            # build/web にサイト: ドキュメント・5 つのモジュール・デモ

pthreads の版はプールのワーカーを前もって作ります (PTHREAD_POOL_SIZE)。WASM の SIMD128 には FMA がないので、いつも exact です。

install と使い方

cmake -B build/out -DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=ON
cmake --build build/out
cmake --install build/out --prefix /usr/local
find_package(hdrgrading 0.0.1 REQUIRED)
target_link_libraries(app PRIVATE hdrgrading::hdrgrading)

または pkg-config --cflags --libs hdrgrading (静的なライブラリは --static。C++ の実行時ライブラリと依存も付く)。どちらのパッケージも install 先を動かして使えます。版は API をフリーズするまで 0.x (SOVERSION 0) で、minor が上がると互換が壊れえます。静的なライブラリは同梱の依存の記号を含むので、自分の libpng や zlib を静的にリンクするアプリは、共有ライブラリか HDRG_WITH_SYSTEM_DEPS を使います。
