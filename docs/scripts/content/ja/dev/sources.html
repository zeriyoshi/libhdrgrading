ライブラリ

場所中身
{{src:include/hdrgrading}}公開ヘッダ: hdrgrading.h (コンテキスト・静止画・設定)・video.h (セッション)・gpu.h (アプリの GPU の device・フレーム・シェーダ)・metadata.h (HDR10+・ST 2094-50 とその T.35 のペイロード)・sidedata.h (ノイズ・動き・粒のサイドデータ)・plugin.h (プラグインのホスト)・filter.h と codec.h (プラグインの ABI)・version.h.in。
{{src:src/context.c}}・{{src:src/params.c}}・{{src:src/priv.h}}コンテキスト・アロケータの補助・統計・プール。プリセット・設定の検査・名前での設定。
{{src:src/convert.c}}・{{src:src/container.c}}静止画の変換。静止画の書き手 (行・ゲインマップとそのメタデータ・プロファイル・光をコーデックへ渡す)。
{{src:src/session}}動画のセッション: session.c (開く・送る・受け取る・待ち行列・描画。フレームをまたぐ統計は STATS の段で)・flash.c (フラッシュリミッタ)・rate.c (出力のレート)・resident.c (GPU に置くフレームとアプリの GPU のフレーム)・latency.c (遅延の見積もりとレポート)・export.c (アプリの GPU 向けのシェーダと状態)。状態は session.h。
{{src:src/pipeline.h}}・{{src:src/pipeline}}系列とそのフレームのパイプライン (pipeline.c)、PREFILTER の連鎖と device の連鎖 (chain.c)、SCALE 段 (scale.c)。共有の部分は parts.h。
{{src:src/lut3d.c}}STATIC のマッピングの 3D LUT。
{{src:src/core}}analyze・noise・plan・render・apply・color・image・yuv・grain・motion・predict (ANALYZE の段へ渡す判定した光の記録と、その確からしさでの上乗せ)・exec・recycle・dynamic (HDR10+・ST 2094-50 の利得の曲線とその T.35 のペイロード)。GPU の上のコア (gpu_core*・gpu_apply・gpu_convert・gpu_analyze・gpu_gather) と、その WGSL ({{src:src/core/wgsl|core/wgsl}}) と生成した msl / spirv / hlsl。
{{src:src/kernels}}SIMD の関数表 (kernels.h)、CPU の検出 (cpu.c)、PQ の表、scalar の参照、ISA ごとの基本演算 (v_*.h) と翻訳単位 (k_*.c)、共有のカーネルの本体 (vmath.h)。
{{src:src/io}}ICC (icc.c)・ゲインマップのメタデータ (gainmeta.c: ISO 21496-1・XMP)。jpegli の C の層は {{src:src/plugins/jpeg/jpegli_compat}} にある。
{{src:src/host}}ホスト (host.c。フィルタのインスタンスとジョブは job.c、device とその GPU の共有は device.c)、内蔵の既定 (defaults.c)、公開の関数 (public.c)、検証、読み込み、段の実行器 (stage.c)、ANALYZE と STATS の段 (analyzer.c・stats.c)、ジョブのフレームの形式 (format.c)、コーデックのホスト (codec_host.c)。
{{src:src/plugins}}内蔵プラグイン。どれも CMake のプロジェクト (cmake/HdrgPlugin.cmake): bilinear・polyphase・edge (+ temporal)・fsr・nis・metalfx・denoise・deblock・dering・defringe・deband・mctf・interp (それぞれ CPU の部分と parts.h。bilinear と metalfx のほかは webgpu_*.c と gk_*.c と wgsl/ の WGSL と生成した msl / spirv も持ち、metalfx は Metal だけ)、predict (+ scripts/predictor/train.py が書く predict_weights)・stats、コーデック jpeg・png・gif・jxl、モジュール avif と heif、shared (blockme・noise)。
{{src:src/gpu}}プロジェクト hdrgrading-gpu: webgpu.c・metal.m・vulkan.c・gk_metal.c / gk_vulkan.c・apple.c、GPU のプラグインの部分 (filter_plugin.c・filter_gk.c・filter_webgpu.c・filter_metal.c・filter_vulkan.c)。ヘッダは include/hdrgrading/gpu。
{{src:src/foundation}}プロジェクト hdrgrading-foundation: memory・math・fmath・hash・fpenv・thread・pool・clock・gpu_share (プラグインの ABI の GPU の共有) (ヘッダは include/hdrgrading/foundation)。
{{src:src/wasm}}ブラウザのモジュールのインタフェース。{{src:src/wasm/demo}}: デモのページ。
{{src:src/bindings}}ffmpeg (フィルタのパッチ)・gstreamer・vapoursynth: 公開ヘッダだけを使う。
