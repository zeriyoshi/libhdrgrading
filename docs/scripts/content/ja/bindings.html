バインディングは、メディアの枠組みのフレームの形の後ろにセッションを置きます。枠組みのバインディングは公開ヘッダだけを使い (ブラウザのモジュールは foundation の memory.h も読む)、どれもライブラリの設定を同じ名前 (hdrg-cli のオプション名: {{api:hdrg_setting_at}}・{{api:hdrg_setting_set}}・{{api:hdrg_setting_get}}。セッションのものは {{api:hdrg_session_setting_set}}。VapourSynth の引数は - を _ にしたもの) で、値は数で受け取ります。プリセット・時間モード・遅延のための自分の選択肢は、代わりにライブラリの値の名前を受け取ります: GStreamer の文字列のプロパティと VapourSynth の引数は {{api:hdrg_setting_parse}} で読み (preset=anime・temporal=recursive・latency=low)、FFmpeg の preset・temporal・latency・gpu は AVOption の定数です。

統計のウィンドウ (past / future が 0 より大きい)・RECURSIVE・TWO_PASS には STATS のフィルタが、出力のレートには動き補償の補間 hdrg.interp.mc が要ります。どちらも HDRG_WITH_TEMPORAL のビルドに入り、既定は OFF です ({{page:video}})。バインディングは自分ではフィルタを足さないので、ほかのビルドではこれらは {{api:HDRG_ERR_UNSUPPORTED}} で失敗します。下の例のうちウィンドウや出力のレートを指定するものは、そのビルドのものです。

FFmpeg

2 つあります: それを使うツールの隣の補助ライブラリ ({{src:tools/ffmpeg}}) と、FFmpeg そのもののフィルタ ({{src:src/bindings/ffmpeg}}) です:

  • 補助ライブラリ {{src:tools/ffmpeg/hdrg_ffmpeg.h|hdrg_ffmpeg.{h,c}}} (libavutil 59 以降、install しない: hdrg-ffmpeg とテストのもの。CMake の HDRG_WITH_FFMPEG、見つかれば ON): AVFrame の画素の形式と色をセッションのものへ対応づけ (平面と NV12 / P010 型の Y'CbCr、詰めた RGB、VideoToolbox のフレーム。PQ と HLG のソースは対象外)、フレームを写さずに包み (参照は release で外す)、AV1 の粒のパラメータを {{api:HDRG_SD_FILM_GRAIN}} で渡し、出力のフレームに色・マスタリングディスプレイ・HDR10+・ST 2094-50 のサイドデータを付けます (ライブラリの T.35 のバイト列を FFmpeg 自身の読み手で読む)。
  • フィルタ libhdrgrading ({{src:src/bindings/ffmpeg/patches}}: FFmpeg に libavfilter/vf_libhdrgrading.c と --enable-libhdrgrading を足すパッチで、upstreamに出せる形)。公開 API だけを使い、install した共有ライブラリを pkg-config で見つけます。選択肢は preset・temporal・latency (既定 offline)・past / future・proxy (解析の縮小。リアルタイムの effort のとき: latency が playback か low)・w / h・fps・threads・gpu・flash_limit・dither・settings (ライブラリの設定の名前、値は数)。出力は PQ / BT.2020 の yuv420p10・p010・rgb48。
scripts/build_ffmpeg.sh --filter build/deps/hdrgrading
build/deps/ffmpeg-filter/bin/ffmpeg -i in.mp4 \
  -vf "libhdrgrading=preset=anime:settings='diffuse-max=1.5'" -c:v libsvtav1 out.mkv

ツールの hdrg-ffmpeg ({{page:tools}}) は補助ライブラリでファイルを丸ごと変換します。

GStreamer

{{src:src/bindings/gstreamer/gsthdrgrading.c}} は要素 hdrgrade を持つプラグイン libgsthdrgrading です (GStreamer 1.20 以降。HDRG_BUILD_GSTREAMER)。未来のウィンドウを遅延にする GstBaseTransform で (LATENCY の問い合わせに足し、EOS で出し切り、FLUSH_STOP で作り直す)、入力は 8〜16bit の平面の YUV (NV12 / P010 などの形も) と詰めた RGB、色は caps の colorimetry と chroma-site から取り、バッファはマッピングしたまま写さずに渡します。出力は I420_10LE の bt2100-pq で、caps にマスタリングディスプレイを付けます。プロパティ latency でプロファイルを選び (既定 playback)、out-rate で出力のレートを変えられます。光を測ったバッファには、HDR10+ と ST 2094-50 の T.35 のペイロードを持つカスタムメタ HdrgDynamicHdrMeta が付きます。ほかのプロパティは設定の表から既定値付きで作ります (符号なし整数・浮動小数点・真偽値)。

GST_PLUGIN_PATH=build/dev gst-launch-1.0 filesrc location=in.mp4 ! decodebin ! videoconvert ! \
  hdrgrade future=4 diffuse-max=1.5 ! x265enc ! h265parse ! matroskamux ! filesink location=out.mkv

VapourSynth

{{src:src/bindings/vapoursynth/hdrg_vapoursynth.c}} は hdrg.Grade を足します (モジュール libhdrgrading_vs。HDRG_BUILD_VAPOURSYNTH)。フレームを任意の順に並列で求めても同じバイトになります (RECURSIVE は近似だけ): セッションの位置に近い要求はセッションを進め、遠い要求は preroll の分だけ前から開き直します ({{api:hdrg_session_preroll}})。色はフレームの属性 (_Matrix・_Transfer・_Primaries・_ColorRange・_ChromaLocation) か引数 matrix・transfer・primaries・range・chromaloc から取ります。preset と temporal (windowed・recursive・static) は名前で受け取り、fpsnum / fpsden で出力のレートを変え、セッションはいつも OFFLINE です。出力は PQ / BT.2020 の 4:2:0 10bit、format="rgb48" なら Display P3 (bt2020=1 で BT.2020) の 16bit の R'G'B' です。出力にはマスタリングディスプレイ・測った光・T.35 のペイロード HDR10Plus (FFMS2 の形) と HdrgST2094_50 を付けます。

clip = core.bs.VideoSource("in.mp4")
hdr = core.hdrg.Grade(clip, past=8, future=4, preset="photo", diffuse_max=1.5)

ブラウザのモジュール

{{src:src/wasm/hdrg_wasm.c}} は JavaScript へ関数だけのインタフェースを出します (hdrg_wasm_context_create・名前での設定・hdrg_wasm_convert・対話プレビューの状態)。5 通りに組み (SIMD128 か scalar、単一スレッドか pthreads、そして emdawnwebgpu と JSPI でブラウザの WebGPU を使う SIMD128)、hdrgrading-<simd128|scalar>-<st|mt|webgpu>.mjs + .wasm になります。静止画を変換します ({{api:hdrg_convert}} と同じ形: 既定はゲインマップの JPEG)。{{src:src/wasm/demo}} のデモは Worker で変換し、HDR の canvas でプレビューします: {{src:src/wasm/demo/preview.js|preview.js}} が 1 フレームのセッションの状態 ({{api:hdrg_session_receive_state}}) の上でライブラリの適用の WGSL を走らせ、スライダに合わせて描き直します。
