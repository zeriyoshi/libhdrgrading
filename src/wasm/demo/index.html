対話プレビュー (WebGPU)

スライダを動かすと、ライブラリの適用シェーダ (WGSL) をこのブラウザの GPU で走らせて、HDR の canvas に描き直します。解析とプランは WASM、適用は GPU です。前処理 (deblock など) は入らず、長辺 2048 画素まで縮小します。境目の左が元の SDR、右が HDR です。

このブラウザは dynamic-range-limit に対応していないため、右の 2 枚は同じに見えます。

ゲインマップ形式は Chrome / Edge / Safari が HDR で表示します。HDR 対応ディスプレイと、OS 側の HDR 表示の設定が必要です。スライダは動かしたものだけがプリセットの値を上書きします。
